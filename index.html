怎么把这个网站放到网上

这个页面是单文件静态网站，不需要服务器，最适合用 GitHub Pages 发布。下面是给自己练习用的最短流程。

路线一：网页拖拽上传（最简单，5 分钟）

  1. 注册并新建仓库登录 GitHub，点右上角 + → New repository，仓库名随便取（例如 850-words），可见性选 Public，点 Create repository。
  2. 改文件名把本文件重命名为 index.html。GitHub Pages 会自动把这个文件当作网站首页。
  3. 上传在仓库页面点 add file → Upload files，把 index.html 拖进去，再点 Commit changes。
  4. 打开 Pages仓库里点 Settings → 左侧 Pages → Branch 选 main、文件夹选 根目录 / → Save。
  5. 访问等一两分钟刷新，页面顶部会给出地址，形如 https://你的用户名.github.io/850-words/。把这个地址发给同学就能打开。

路线二：用 Git 命令行（练习真正的提交流程）

  1. 准备目录新建一个空文件夹，把 index.html 放进去，在该目录里执行 git init。
  2. 提交依次执行 git add index.html 和 git commit -m "first page"。
  3. 关联仓库在 GitHub 上先建好空仓库，然后执行 git remote add origin 仓库地址，再 git push -u origin main（分支名以你仓库实际的为准）。
  4. 开启 Pages和路线一第 5 步一样：Settings → Pages → 选分支 → Save。

改内容之后怎么办？改完本地文件，再走一遍 git add → git commit → git push；网页地址不变，浏览器可能需要按 Ctrl+F5 强制刷新才能看到新版。

常见问题

打开是 404？多半是文件名不对——必须是 index.html（全小写），而且要放在仓库根目录或 Pages 指定的文件夹里。

地址里少了后半截？仓库名会出现在网址路径里，形如 /仓库名/，完整地址以 Settings → Pages 页面显示的为准。

改了没变化？GitHub Pages 发布有 1～2 分钟延迟，另外浏览器会缓存，强制刷新即可。

会不会很贵？公开仓库的 GitHub Pages 免费额度对这种纯静态页面完全够用。
